# SARDAR — интернет-магазин одежды (Астана)

Статический сайт-магазин: каталог с фильтрами, карточки товаров с выбором цвета и размера, корзина с итоговой суммой и доставкой СДЭК, оформление заказа в WhatsApp. Работает бесплатно на **GitHub Pages**, без сервера и без базы данных.

- 105 моделей, 406 цветов, точные остатки по каждому размеру
- Отдельная страница на каждый товар и каждую категорию (хорошо индексируется Google, Яндекс и нейросетями)
- Мобильная версия в первую очередь
- Готовые фиды для ИИ и маркетплейсов: `llms.txt`, `llms-full.txt`, `data/products.json`, `data/products.csv`, `feed.xml` (Google Merchant)

## 1. Перед запуском — заполните `config.json`

Откройте `config.json` и замените:

| Поле | Что вписать |
|---|---|
| `whatsapp` | Номер WhatsApp для заказов (уже стоит `77075061928`) |
| `phone_display` | Тот же номер для показа (`+7 707 506 19 28`) |
| `site_url` | Адрес сайта, например `https://ВАШ_ЛОГИН.github.io/sardar-shop` |
| `delivery.zones[].price` | Сейчас `null` — доставка оплачивается отдельно по тарифу СДЭК. Если захотите фиксированную цену для района — впишите число |
| `delivery.free_from` | Сумма для бесплатной доставки (сейчас `0` — бесплатной доставки нет) |
| `payment_methods` | Способы оплаты, которые вы реально принимаете |
| `seller.bin`, `seller.address` | БИН и адрес ИП (показываются в подвале) |
| `instagram`, `telegram`, `email` | Если есть — появятся в контактах |

## 2. Публикация на GitHub Pages (один раз, ~10 минут)

1. Зарегистрируйтесь на github.com и нажмите **New repository**. Имя — `sardar-shop`, тип **Public**.
2. На странице репозитория: **Add file → Upload files** → перетащите **всё содержимое** этой папки (включая скрытую папку `.github`; если её не видно — включите в Проводнике «Показывать скрытые элементы»). Нажмите **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте вкладку **Actions** — через 1–2 минуты появится зелёная галочка. Сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/sardar-shop/`.
5. Впишите этот адрес в `config.json → site_url` (можно прямо на GitHub: открыть файл → карандаш → Commit). Сайт пересоберётся сам.

**Свой домен** (например `sardar.kz`): создайте в корне файл `CNAME` с одной строкой `sardar.kz`, у регистратора домена добавьте CNAME-запись на `ВАШ_ЛОГИН.github.io`, а в `config.json` поменяйте `site_url`.

После каждого изменения любого файла в ветке `main` сайт пересобирается автоматически (`.github/workflows/pages.yml`).

## 3. Как приходят заказы

Цены на сайте — цены продажи за 1 шт (из PDF-каталога), доставка СДЭК оплачивается покупателем отдельно.

Покупатель собирает корзину → выбирает район доставки → вводит имя, телефон, адрес → нажимает **«Отправить заказ в WhatsApp»**. Открывается WhatsApp с готовым текстом:

```
Здравствуйте! Новый заказ SD-1710-9609 с сайта SARDAR
1) Платье-поло на трех пуговицах — Розовый, размер S, 1 шт × 1 520 ₸ = 1 520 ₸ [арт. SD057-01]
Товары: 1 520 ₸
Доставка (СДЭК, Косшы): оплачивается отдельно по тарифу СДЭК
ИТОГО за товары: 1 520 ₸ (+ доставка СДЭК отдельно)
Имя / Телефон / Адрес / Оплата / Комментарий
```

Артикул `SD057-01` = модель 57, цвет №1 — по нему легко найти вещь на складе.

### Учёт продаж в Google Таблице

Каждый заказ с сайта автоматически записывается в Google Таблицу, остатки уменьшаются, а сайт показывает актуальные остатки: проданный размер становится недоступным, распроданная модель помечается «Нет в наличии».

В таблице `SARDAR_учет_продаж.xlsx` (лежит **рядом** с папкой проекта — в GitHub её не кладите, там закупочные цены) пять листов:

| Лист | Что там |
|---|---|
| **Сводка** | выручка, прибыль, маржа, средний чек, оплачено / ждём оплату, остаток склада в деньгах; разбивка по месяцам, категориям, источникам и статусам |
| **Заказы** | один заказ = одна строка: статус, оплата, клиент, адрес, трек СДЭК, сумма, себестоимость, прибыль |
| **Позиции** | каждая проданная вещь: артикул-размер, кол-во, цена, закупка |
| **Остатки** | 816 строк «артикул-размер»: начальный остаток, продано, остаток, цена продажи, закупочная цена |
| **Как пользоваться** | краткая памятка |

**Подключение (один раз, ~10 минут):**

1. Откройте drive.google.com → **Создать → Загрузить файл** → выберите `SARDAR_учет_продаж.xlsx`.
2. Откройте файл двойным щелчком → вверху **Файл → Сохранить как Google Таблицу**. Дальше работайте с этой копией (у неё нет значка XLSX).
3. В Google Таблице: **Расширения → Apps Script**. Удалите всё в редакторе, вставьте целиком содержимое файла `google-sheets/Code.gs` из этого проекта, нажмите 💾 **Сохранить**.
4. Справа вверху **Начать развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**:
   - Описание: `SARDAR`
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   
   Нажмите **Начать развертывание** → **Предоставить доступ** → выберите свой Google-аккаунт → «Дополнительные настройки» → «Перейти на страницу…» → **Разрешить**.
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) и вставьте в `config.json` → `"order_webhook": "https://script.google.com/macros/s/…/exec"`. Сохраните — сайт пересоберётся.
6. Обновите страницу таблицы — появится меню **SARDAR**. Пункт «Проверить подключение сайта» покажет, что всё на месте.

**Как вести учёт:**

- Заказ с сайта появляется со статусом **Новый**: вещи сразу резервируются (уходят из остатка).
- Меняйте **Статус**: Новый → Подтверждён → Отправлен → Доставлен. **Отменён** и **Возврат** возвращают вещи в остаток и убирают сумму из выручки.
- **Оплачен = Да**, когда пришли деньги. В **Трек СДЭК** впишите номер отправления.
- **Доставка СДЭК, ₸** заполняйте, только если доставку оплатили вы — она вычтется из прибыли.
- Продажи **вне сайта** (WhatsApp, Kaspi, Instagram, магазин): меню **SARDAR → Добавить продажу вручную**. Начните вводить артикул (например `SD057-01-S`), цена подставится сама — её можно поменять, если дали скидку.
- **Новая поставка**: увеличьте «Начальный остаток» в листе «Остатки».
- Строки, подсвеченные жёлтым, — заказы с предупреждением (не хватило остатка или неизвестный артикул), смотрите «Комментарий».

**Уведомления в Telegram (по желанию).** В начале `Code.gs` впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (как их получить — описано там же), затем **Развертывание → Управление развертываниями → ✏️ → Версия: Новая → Развернуть**. Уведомление придёт, даже если покупатель не нажал «Отправить» в WhatsApp, — заказ уже записан в таблицу.

> После любых правок `Code.gs` обязательно делайте **новую версию** развертывания (как выше), иначе сайт продолжит работать со старым кодом. Адрес `/exec` при этом не меняется.

**Пересоздать таблицу из нового файла остатков** (если пришла новая партия Teez):

```bash
python tools/make_ledger.py Остатки_Teez.xlsx ../SARDAR_учет_продаж.xlsx
```

## 4. Как обновлять товары

**Поменять цену, описание, материал** — в `data/catalog.json` у нужного товара (`price`, `old_price` — зачёркнутая старая цена, `description`, `material`). Можно править прямо на GitHub.

**Обновить остатки из нового файла Teez** (нужен Python 3 на компьютере):

```bash
pip install openpyxl
python tools/import_teez.py Остатки.xlsx Каталог_с_ценами.pdf
python build.py
```

Скрипт возьмёт количества и размеры из xlsx, розничные цены из PDF и **сохранит ваши ручные правки** (цены, описания) по номеру модели. Закупочные цены из xlsx на сайт **не попадают**.

**Фото товаров.** В `images/` лежат фото для каталога (600×800), в `images/hq/` — крупные для карточки товара (1200×1600, открываются на весь экран с увеличением). Имя файла — код фото из `data/catalog.json` (`image` / `variants[].img`). Чтобы заменить фото, положите новый файл с тем же именем в обе папки (формат `.webp`, пропорции 3:4).

## 5. Почему сайт «дружит» с нейросетями и поиском

- Каждый товар — отдельная HTML-страница с полным текстом (не нужно выполнять JavaScript, чтобы прочитать цену и размеры).
- Разметка **Schema.org JSON-LD**: `ProductGroup` с вариантами цвет/размер, ценой в KZT, наличием, условиями доставки и возврата; `OnlineStore`, `BreadcrumbList`, `FAQPage`, `ItemList`.
- **`/llms.txt`** и **`/llms-full.txt`** — описание магазина и весь каталог простым текстом для ChatGPT, Claude, Perplexity, Gemini и др.
- **`/data/products.json`** и **`/data/products.csv`** — каталог в машиночитаемом виде.
- **`/feed.xml`** — фид для Google Merchant Center (бесплатные товарные объявления в Google).
- **`robots.txt`** явно разрешает GPTBot, ClaudeBot, PerplexityBot, Google-Extended, YandexBot и др.; есть `sitemap.xml`.

После запуска добавьте сайт в **Google Search Console** и **Яндекс.Вебмастер** и отправьте `sitemap.xml`.

## 6. Структура

```
config.json            — настройки магазина (контакты, доставка, оплата)
data/catalog.json      — товары: цены, цвета, размеры, остатки
images/                — фото товаров (.webp)
assets/                — стили, скрипт магазина, шрифты
build.py               — сборка сайта в папку site/
tools/import_teez.py   — импорт остатков из xlsx + цен из PDF
tools/make_ledger.py   — создание таблицы учёта продаж (xlsx для Google Таблиц)
google-sheets/Code.gs  — скрипт для Google Таблицы: приём заказов, остатки, ручные продажи
.github/workflows/     — автопубликация на GitHub Pages
site/                  — готовый собранный сайт (создаётся build.py)
```

Посмотреть сайт на своём компьютере: `python build.py`, затем `cd site && python -m http.server 8000` и откройте http://localhost:8000
